High-Fidelity SVG Animation to Video & Animated Image Studio

Transform animated SVGs (CSS & SMIL) into MP4, WebM, MKV, MOV, aPNG, or GIF with full alpha-channel transparency — directly in your browser or via CLI/MCP.

Why Use SVG to Video?

Transparent Backgrounds

Export your animations with a full alpha channel using WebM or aPNG, and optimized indexed transparency with GIF89a. Perfect for overlays in video editing tools or web use.

Privacy-First

The Web Studio runs entirely in your browser—your SVG files never leave your computer.

Frame-Accurate

Our engine scrubs both the Web Animations API and native SVG SMIL, ensuring every frame is captured exactly as rendered.

AI Agent Native

Native Model Context Protocol (MCP) server and Agent Skill (SKILL.md) support indexed on the official MCP Registry (mcp.json) and hosted live on HuggingFace Spaces.

Universal Animated Formats

Beyond video, generate lightweight Animated PNGs (aPNG) and GIFs with deterministic 8x8 Bayer ordered dithering to eliminate temporal fluttering on animated gradients, with full control over background transparency.

Granular Quality & Rate Control

Fine-tune output file size and visual fidelity with custom target bitrates (--bitrate), Constant Rate Factor (--crf 0-63), and quality percentages (--quality 1-100) across video (MP4, WebM, MKV, MOV) and animated formats (GIF color quantization, aPNG compression).

Configurable Animation Looping

Full control over animation playback loops for animated formats (GIF, aPNG) and live preview—toggle infinite looping or single-play export across Web Studio, CLI (--loop <count>, --no-loop), and MCP integrations.

Copy to Clipboard

Instant export to Base64 Data URL—copy your video and embed it directly into your HTML, CSS, or JS code without manual downloads. Perfect for rapid prototyping and developers.

Metadata Injection

Support for custom titles and comments across video (MP4, WebM, MKV, MOV) and animated image (aPNG, GIF) formats.

Versatile

Whether you need an accessible Web Studio for quick conversions or a powerful CLI tool for batch automation and CI/CD pipelines, this project has you covered.

Frequently Asked Questions

Web Studio

Are my SVG files uploaded to any external server?

No. The Web Studio runs 100% client-side inside your browser using WebCodecs and the Web Animations API. Your SVG source code and exported video frames never leave your local device.

How does frame scrubbing work for CSS and SMIL animations?

The engine mounts your SVG in an isolated offscreen canvas, programmatically pauses all CSS and SMIL animations, and advances the animation timeline frame by frame (e.g. at 24, 30, or 60 FPS) to guarantee 100% frame accuracy without skipped frames.

How does the Web Studio render high-quality, flicker-free GIFs without a server?

Most browser-based GIF tools either snap colors coarsely (causing color banding) or use error diffusion dithering (which produces moving, noisy speckles across frames). The Web Studio features an in-browser encoder with custom 8x8 Bayer ordered dithering and 16-bit rgb565 palette quantization. This disperses narrow color transitions smoothly without temporal fluttering, delivering FFmpeg-grade GIF quality directly inside your browser.

How do I preserve transparent backgrounds in exported videos?

Select WebM, aPNG, or GIF as your output format, check the "Transparent Background" toggle, and ensure your SVG root element does not declare an opaque background rect.

How do I disable looping for animated GIFs or aPNGs?

In the Web Studio, uncheck the Loop Animation toggle under the Output Format selector (enabled for animated formats like GIF and aPNG; disabled for video formats). In the CLI, use --no-loop (or --loop 1 / --loop -1). In the MCP server, set "loop": false or "loop": 1.

CLI, Docker & MCP Automation

Can I automate conversions in CI/CD pipelines or AI agents?

Yes! You can use the official CLI tool (npx -y @gehdoc/svg-to-video), the Docker image (gehdoc/svg-to-video), or connect to the Model Context Protocol (MCP) server for Claude Desktop, Cursor, and Antigravity.

Do I need to manually install FFmpeg to use the CLI?

No. The CLI automatically uses system FFmpeg if present on your $PATH, or falls back to a bundled static FFmpeg binary out of the box. You can also specify a custom binary path using --ffmpeg-path <path> or the FFMPEG_PATH environment variable.

How do I control output video quality and file size?

You can fine-tune output size and visual fidelity in the CLI and MCP tools using --bitrate <rate> (e.g. 5M, 2000k), Constant Rate Factor --crf <0-63> (e.g. 18 for near-lossless, 20 by default, 28 for compact), or --quality <1-100> for animated GIF (color palette quantization) and aPNG (zlib compression).
