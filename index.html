Developer CLI, Docker & Model Context Protocol (MCP)

CLI & Docker Automation
# Node.js (auto-detected duration)
npx -y -p @gehdoc/svg-to-video svg-to-video input.svg 60 ./out-dir

# Node.js (explicit duration & GIF output)
npx -y -p @gehdoc/svg-to-video svg-to-video input.svg 60 ./out-dir -d 5 --format gif --transparent

# Node.js (custom resolution dimensions e.g. vertical 1080x1920)
npx -y -p @gehdoc/svg-to-video svg-to-video input.svg 60 ./out-dir --resolution 1080x1920

# Node.js (animated PNG output)
npx -y -p @gehdoc/svg-to-video svg-to-video input.svg 60 ./out-dir -d 5 --format apng

# Docker (zero local dependencies; requires --shm-size=2gb for Chromium rendering; add :Z to -v for SELinux / Fedora)
docker run --rm --shm-size=2gb -e PUPPETEER_ARGS="--no-sandbox" -v $(pwd):/data:Z gehdoc/svg-to-video /data/input.svg 60 /data/out-dir -d 5 --format gif

Frequently Asked Questions

Are my SVG files uploaded to any external server?

No. The Web Studio runs 100% client-side inside your browser using WebCodecs and the Web Animations API. Your SVG source code and exported video frames never leave your local device.

How does the Web Animations API frame scrubbing work?

The engine mounts your SVG in an isolated offscreen canvas, programmatically pauses all CSS and SMIL animations, and advances the animation timeline frame by frame (e.g. at 24, 30, or 60 FPS) to guarantee 100% frame accuracy without skipped frames.

Can I automate conversions in CI/CD pipelines or AI agents?

Yes! You can use the official CLI tool (npx -y @gehdoc/svg-to-video), the Docker image (gehdoc/svg-to-video), or connect to the Model Context Protocol (MCP) server for Claude Desktop, Cursor, and Antigravity.

How do I preserve transparent backgrounds in exported videos?

Select WebM, aPNG, or GIF as your output format, check the "Transparent Background" toggle, and ensure your SVG root element does not declare an opaque background rect.
